CallRules Troubleshooting

Start with Settings → Troubleshoot issues. Its cards reflect the features configured on your device and offer safe fixes.

Incoming calls are not blocked

  • Confirm CallRules holds Android's Call Screening role and the Dashboard says protection is active.
  • Make sure Call Rules are not paused and the intended Incoming or Both rule is enabled.
  • Review Allow rules and the whitelist, which take priority over blocking.

Outgoing rules do not run

  • Open Settings → Outgoing call protection and grant the Call Redirection role.
  • Enable outgoing-rule evaluation and confirm the rule direction is Outgoing or Both.
  • If a PIN-required imported rule reports setup required, create the shared PIN.
  • For an approved replacement call, grant Phone permission. CallRules does not need Call Log or obsolete outgoing-call permissions.
  • Allow notifications so a waiting confirmation is visible when Android cannot open CallRules directly.

Confirmation was cancelled, expired, or did not redial

The original call is cancelled before confirmation. Cancelling the screen or waiting about 60 seconds places no call. After approval, CallRules rechecks the current rules, role, confirmation method, and Phone permission. If anything changed—or Android could not place the call—correct the reported issue and dial again. An approval is one-use only.

Location rule does not match

Location permissions are needed only when an enabled incoming rule has a location constraint. Allow foreground location first, then choose Android's background option if the rule must work while CallRules is closed or locked. If access is denied, the location condition is treated as unmet.

Lifetime Pro or Restore is unavailable

  • Use the Play-installed build and the same Google account that owns the purchase.
  • Check Play Store connectivity, then use Retry Google Play or Restore purchase.
  • The product can be unavailable for an ineligible account, region, or unpublished test build. Pending purchases unlock only after Google Play completes them.

Still need help?

In Settings, choose Report a problem. Review the text before sending and attach sanitized diagnostics only if you want to. Dictation and sharing are user initiated.
